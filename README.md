# Testing an AI-Generated App - Portfolio Project by Kacper Mirecki

## Description

This repository contains documentation describing testing process for a restaurant Table Reservation System. Application is generated by Claude Code.

**Tech Stack of the Tested Application:** Laravel 13 + Vue 3 + Inertia + MySQL + Reverb
**Testing Environment:** local, docker compose.
