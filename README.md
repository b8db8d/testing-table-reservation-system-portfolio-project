# Testing an AI-Generated Reservation System - Portfolio Project by Kacper Mirecki

## Description

A [Table Reservation System](https://github.com/b8db8d/Table-Reservation-System) was generated by Claude Code using the [workflow](https://github.com/LaravelDaily/AI-Workflows-For-Laravel) created by [Povilas Korop](https://github.com/PovilasKorop).
The AI generated its own Pest test suite, which passed entirely.

This repository documents what manual exploratory testing found anyway: across the reservation flow, admin panel, signed URL handling, and real-time updates.

**Tech Stack of the Tested Application:** Laravel 13 + Vue 3 + Inertia + MySQL + Reverb
**Testing Environment:** local, Docker Compose.

## What This Project Demonstrates

- **Exploratory testing methodology** — session-based investigation surfacing bugs the AI-generated test suite missed
- **Bug reporting discipline** — structured reports with reproduction steps, severity calibration, evidence, and traceability to user stories
- **Database-layer verification** — SQL queries to confirm UI symptoms reflect actual data state (see BUG-002 for canonical example)
- **Test design across techniques** — boundary values, state transitions, RBAC negative tests
- **E2E test automation with CI/CD with GitHub Actions** — Playwright + TypeScript with Page Object Model, fixtures, multi-actor flows via separate browser contexts
- **Infrastructure as test environment** — Docker Compose setup with isolated services (app, Reverb WebSocket, MySQL, Mailpit)
