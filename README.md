# Testing an AI-Generated Reservation System - Portfolio Project by Kacper Mirecki

## Description

A [Laravel/Vue Restaurant Reservation System](#) was generated by Claude Code using the [workflow](https://github.com/LaravelDaily/AI-Workflows-For-Laravel) created by [Povilas Korop](https://github.com/PovilasKorop).
The AI generated its own Pest test suite, which passed entirely.

This repository documents what manual exploratory testing found anyway: across the reservation flow, admin panel, signed URL handling, and real-time updates.

**Tech Stack of the Tested Application:** Laravel 13 + Vue 3 + Inertia + MySQL + Reverb
**Testing Environment:** local, Docker Compose.
